## What to verify after the run

### 1. tables_inventory.md was produced by extract phase

```bash
ls -la tables_inventory.md
head -30 tables_inventory.md
# Should show "<!-- inventory_schema_version: 1 -->" header
# and ### report_tbl_01, report_tbl_02, ... entries
```

### 2. results.v1 emitted tables_manifest.tsv

```bash
cat tables_manifest.tsv
# Expected: header + 1-6 data rows
# Schema: paper_order_n<TAB>table_id<TAB>inventory_lookup_name
```

### 3. 02_results.md has (Table N) callouts

```bash
grep -n "(Table " 02_results.md
# Expected: at least 1 (Table N) callout matching manifest entries
```

### 4. check_tables_manifest.py ran clean

```bash
cat audit/tables_manifest_warnings.txt
# Expected: 0 WARNs. NOTEs for unused manifest entries are acceptable.
```

### 5. embed_tables injected table blocks

```bash
grep -c "\*\*Table [0-9]" 02_results.md
# Expected: matches the number of (Table N) callouts
cat audit/embed_tables.log
# Expected: "embedded: N total across M section(s)"
```

### 6. assemble_docx rendered tables

```bash
# If manuscript.docx exists, open it and verify tables render as
# Word Table Grid (not raw markdown). assemble_docx.py's render_table()
# already handles this — confirm visually.
```

### 7. Caption quality spot-check

For each embedded table, verify:
- Caption is descriptive (not just "Table" or a filename)
- Caption relates to the table's column names
- Table content matches what's in tables_inventory.md

## Known risks

- **LLM may not emit tables_manifest.tsv on first try.** The prompt
  contract is new; results.v1 may need 1-2 retries. The retry helper
  will catch missing-file failures.
- **Caption gate may be too strict.** If results.v1 selects tables
  whose inventory captions fail the sufficiency gate, embed_tables
  will skip them silently. Check audit/embed_tables.log for WARNs.
- **Wide tables (>8 cols).** check_tables_manifest will warn. These
  may render poorly in docx; visual review needed.
