v0.4-dev — Tier 8 (caption richness) infrastructure complete; pre-Phase 5

Pre-ship checkpoint: all Phase 0 through Phase 4c work landed and
tested ($0 LLM cost across dev; 414 unit tests pass). Phase 5 (live
retest gate, $10 cap) and Phase 6 (v0.4.0 ship) follow on top.

The v0.4 thesis: close the caption-richness gap. v0.3 shipped 10
inline Pictures + 10 single-line Caption paragraphs in the
functional_dark_matter manuscript.docx. ICMJE/Nature-style 50–200 word
legends were deferred. v0.4 adds a four-source caption ladder
(notebook prose walk-back / matplotlib AST / prose-side panel
callouts / LLM synthesis with provenance check) producing structured
multi-line descriptions on figures where notebooks have signal,
falling back to LLM synthesis with anti-fabrication discipline on
sparse-source figures.

Eight architectural pieces landed (Phase 0–4c from
smoke-test/v0_4_punch_list.md). Empirical-data-driven: Phase 1a smoke
against functional_dark_matter (41 figures across 8+ notebooks)
revealed that ~37% of figures generate en bloc under one section
heading with no per-figure descriptive markdown — a finding that
reshaped the Phase 4c sufficiency-gate threshold from "<50 chars
prose" to "<30 non-heading-words prose AND no AST title/axes".

Phase 0 — v0.3.1 cosmetics absorbed
  Two paper_writer.sh patches: (1) misleading "Copied 0 figure(s)"
  fallback removed (the v0.1/v0.2 grep-based fallback was meaningful
  when prose contained filenames; v0.3+ prose has (Fig. N) callouts
  and results.v1's Bash tool owns figure-copy directly). (2)
  FIGURES_OUT_DIR explicitly passed to results.v1 user_prompt
  (results.v1.md line 107 declared this input; orchestrator was
  failing to pass it; LLM was inferring from DRAFT_DIR).

Phase 1a — extract_figures.py: notebook cell-attribution rewrite
  Old "consume one md cell, attribute to first following code cell"
  model silently failed on the dominant idiom (md → data-prep code →
  plot+savefig code). New _collect_md_walkback walks backward from
  each savefig cell through ALL preceding cells, accumulating
  markdown until a section header (line beginning with `#`).
  Multiple savefigs in one section legitimately share upstream
  prose — no consume semantic. Smoke against functional_dark_matter:
  39/41 figures gain notebook-derived prose (was ~0 in v0.3); 24/41
  rich (≥5 non-heading words), 15/41 just-heading. The 15
  just-heading figures motivate the Phase 4c sufficiency-gate
  revision (heading-line strip before word count).

Phase 1b — extract_figures.py: structured CaptionDescriptor + v2 schema
  PanelDescriptor + CaptionDescriptor dataclasses. FigureRecord gains
  a description: CaptionDescriptor field. _DESCRIPTION_TEXT_CAP=4000
  chars (empirical: max walk-back across functional_dark_matter is
  3424 chars; p95=2782; comfortable headroom). figures_inventory.md
  bumped to v2 schema with `<!-- inventory_schema_version: 2 -->`
  header on line 1 + per-figure **Description:** block (italic-
  labeled bullets for Title/Axes/Legend/Panels + blockquote for
  notebook_prose + provenance line). Downstream consumers verified
  unaffected by schema bump: paper_writer_helpers' caption parser
  round-trips v2 cleanly (locked by regression test);
  check_figures_manifest reads only the manifest TSV; paper_writer.sh
  references inventory by path only; results.v1.md treats inventory
  as Read-tool source (richer Description block is net-positive
  signal).

Phase 2 — extract_figures.py: matplotlib AST extraction (Source 3)
  PlotCallExtraction dataclass + _extract_plot_calls(setup_cell,
  savefig_cell, savefig_line, prev_savefig_line). Per-savefig scope
  partitioning at savefig boundaries via line-number windows;
  supports multi-savefig-per-cell idiom. _classify_plot_call handles
  plt.title / plt.suptitle / plt.{x,y}label / ax.set_{title,xlabel,
  ylabel} / axes[i,j].set_* (panel-level) / plt.legend / plt.subplots
  (grid declaration → row-major panel letters) / plt.subplot(N,M,k)
  (current-position context) / plt.figure() (boundary-reset).
  String-literal argument extraction only — interpolated f-strings
  return None (no fabrication); wrapper-function plot calls
  (volcano_plot(df)) are intentionally not chased into other modules
  (honest scope cap). Cross-cell over-attribution bug discovered +
  fixed during smoke: when fig01's draw cell is fig02's
  setup_cell_source, fig01's panel titles were leaking into fig02
  via first-occurrence-wins. Fix: treat plt.figure() and
  plt.subplots() as figure-boundary calls that wipe per-figure state.
  Smoke (post-fix) against functional_dark_matter: 39/41 with
  matplotlib_ast trace, 28/41 with title, 31/41 with axes_labels,
  7/41 with multi-panel detection (verified by spot-check of fig01,
  fig02 source).

Phase 3 — descriptor flow-through to manuscript output
  Three new helpers in paper_writer_helpers.py:
  _parse_figures_inventory_descriptions (v2 inventory parser; v1
  returns {} for graceful fallback), _detect_prose_panel_callouts
  (Stratum 2 prose-side scan for (Fig. N[A-Z]) callouts; ±1 sentence
  context per letter), _assemble_description_text (composes single-
  line description with empty-field elision; multi-panel "(A) ...
  (B) ..." form; redundant author-side "A. " / "B) " prefix
  stripping; flattens newlines; capped at max_chars=1500).
  _build_figure_map returns dict[int, dict] (was tuple[str, str] in
  v0.3) with keys filename / caption / descriptor.
  cmd_resolve_figures emits 4-column TSV (paper_order_n, filename,
  caption, description). _embed_figures_in_text injects italic
  *Description: <text>* paragraph after the image tag when
  descriptor is non-empty; per-call prose-panel detection merges
  Stratum 2 callouts into the description. assemble_docx.py upgrades
  italic *Description: ...* paragraphs IMMEDIATELY following an image
  to Caption style (visual continuity with figure caption above);
  Description paragraphs NOT after an image stay Normal italic. Bug
  caught + fixed during smoke: panel-entry separator drift between
  emitter (`, `) and parser (`;`) collapsed all panels into the first
  letter's title; pinned by integration round-trip test.

Phase 4a — prompts/figure_caption.v1.md (Source 4 prompt; 294 lines)
  Mirrors results.v1's skeleton (mission → inputs → output → discipline
  pass → worked example → closing message → escape hatches). Inputs
  via user_prompt only (no Read tool for input gathering): figure_id,
  short_caption, structured_descriptor (full Phase 1b/2 schema),
  prose_panel_callouts (Stratum 2 dict), report_prose, results_section
  _prose, max_words. Output: single markdown paragraph, 50–200 words,
  written via Write tool to output_path. Anti-fabrication discipline
  in three checks: numerical-claim trace (every digit greppable in
  inputs; common fabrication patterns enumerated), panel-letter trace
  (each (X) mention must trace to descriptor.panels OR
  prose_panel_callouts), word-count compliance (>max_words HALT-and-
  trim; <30 explicit fall-back signal). Worked example uses synthetic
  fig03 input bundle showing every numerical claim's traceability.
  Closing message: figure_caption_<N> word_count <W> traceable_claims
  <K> panel_count <P>. Escape hatch on empty-everywhere inputs:
  refuses to fabricate, halts with explicit "no traceable source
  signal" error.

Phase 4b — tools/check_caption_provenance.py (sixth post-checker)
  Joins the existing five (check_throughline_glyphs,
  check_scope_coherence, check_overclaim, check_repair_scope,
  check_figures_manifest) following the same standalone-script
  pattern: stderr WARN/NOTE format, advisory exit-0, importable for
  unit testing. Reads audit/figure_caption.v1.metadata.json; for
  each entry with source_chosen='llm', loads the caption text and
  runs four checks against the input bundle: numerical-claim trace
  (comma-normalized + unit-suffix-stripped lookups; deduped),
  named-entity trace (multi-word capitalized phrases; common-prose
  allow-list for "Each Panel" / "Both Panels" / etc.), panel-letter
  hallucination (regex matches `(A)` / `(panel A)` / `panel A` /
  `panel labeled A` forms; valid letters from descriptor.panels OR
  prose_panel_callouts keys), word-count compliance (30-200 band;
  below-30 emits explicit fall-back recommendation).

Phase 4c — orchestrator wiring + sufficiency gate
  Two new bash phases in paper_writer.sh, two new Python helper
  subcommands in paper_writer_helpers.py.

  Sufficiency gate (revised after Phase 1a empirical data):
    Source 4 invoked iff EITHER
      (a) word_count(strip_heading_lines(notebook_prose)) < 30, OR
      (b) descriptor.title is None AND descriptor.axes_labels is empty.

  build-caption-bundles: reads manifest + v2 inventory + REPORT.md
  + 02_results.md; for each figure applies the gate; writes per-
  figure bundle JSONs to <draft_dir>/audit/caption_bundles/figure_<N>
  .bundle.json + initializes audit/figure_caption.v1.metadata.json
  with all entries classified by source_chosen. Stdout is the list of
  figure_ids needing Source 4 invocation (one per line; bash
  iterates).

  compute-caption-stats: after the LLM writes the caption, counts
  word_count / panel_count / traceable_claims (using the same regexes
  as check_caption_provenance) and updates the corresponding entry
  in metadata.json with closing_message stats. Idempotent.

  phase_caption_synthesis(project_root, draft_dir, model): calls
  build-caption-bundles → list of figure_ids; for each, reads bundle
  JSON, formats user_prompt with the JSON inlined, invokes
  figure_caption.v1.md via invoke_claude_with_retry. After Write
  succeeds, calls compute-caption-stats. LLM-failure case: log_warn
  + continue → orchestrator proceeds; figure falls back to Phase 3's
  deterministic descriptor description.

  phase_check_caption_provenance(draft_dir): standard post-checker
  invocation pattern; pipes stderr to audit/caption_provenance_warnings
  .txt; surfaces WARNs via emit-next-actions.

  Wired in main case block between phase_check_figures_manifest and
  phase_embed_figures. Rewrite-loop integration intentionally OMITTED
  for v0.4 (Source 4 not re-invoked on rewrite passes; figures with
  new (Fig. N) callouts get the deterministic descriptor description).
