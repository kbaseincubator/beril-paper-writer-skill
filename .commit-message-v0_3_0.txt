v0.3.0 — figures + docx assembly tier

The v0.3 thesis: close the figure-embedding loop end-to-end. v0.2
shipped manuscript.md with no figure embeddings; users had to insert
figures by hand. v0.3 produces manuscript.docx with inline Pictures +
Caption-styled paragraphs, end-to-end from a fresh drafting run, with
no manual intervention beyond the throughline pick.

Four architectural pieces landed (Tier 2.1–2.4 from
smoke-test/v0_3_punch_list.md), proven by live retest:

Tier 2.4 — commands/assemble.py wired to tools/assemble_docx.py
  CLI surface no longer a stub. Validates draft_dir + manuscript.md;
  --format docx subprocesses tools/assemble_docx.py with
  sys.executable; --format md is identity; --format pdf rejected
  (post-MVP). Located via importlib.resources matching draft.py
  pattern.

Tier 2.3 — tools/assemble_docx.py — full markdown→docx renderer
  ~470 lines, hand-rolled, no new deps beyond python-docx>=1.1.0.
  Block parser (state machine) + inline tokenizer (single regex with
  named groups). Supports H1-H6, paragraphs, bullet/numbered lists,
  blockquotes, markdown tables, fenced code blocks, block-level
  images, horizontal rules. Inline: code spans, bold, italic, inline
  links (text + parenthetical URL form). Bare [N] citations preserved
  verbatim (does NOT match link regex; verified). Image rendering:
  block-form ![Figure N: caption](figures/<filename>) → centered
  Picture (Inches(6)) + Caption-styled paragraph. Path validation
  rejects absolute/parent-relative; missing files emit soft
  [FIGURE MISSING: …] placeholder. Style fallbacks for Caption /
  List Bullet / List Number / Quote / Table Grid. 26 unit tests
  in tests/unit/test_assemble_docx.py.

Tier 2.1 — results.v1 prompt edit + figures_manifest.tsv contract +
post-checker + resolve-figures helper
  (a) prompts/results.v1.md: 6 edits — (Fig. N) callouts upgraded to
      load-bearing; HALT discipline in self-review; new
      figures_manifest.tsv emission step (3 cols: paper_order_n,
      filename, inventory_lookup_name; tab-separated; banned-tab
      discipline; captions OUT of manifest to sidestep
      LLM-emitted-JSON-with-quotes trap); anti-example pair for
      missing-callout failure mode; closing-message template extended.
  (b) tools/check_figures_manifest.py — fifth post-processor in v0.2
      pattern. Four checks: schema, filename existence, orphan-figure
      detection, callout cross-walk. Always exits 0; surfaces via
      emit-next-actions. Wired between phase_finalize_citations and
      phase_embed_figures. emit-next-actions extended with new
      "## Figures-manifest warnings" section.
  (c) paper_writer_helpers.py resolve-figures subcommand — joins
      manifest with figures_inventory.md; emits paper_order_n →
      caption + filename TSV. Captions sourced from inventory's
      caption-candidate ranking (REPORT > notebook > filename).
      Banned-tab + banned-newline + banned-bracket discipline applied
      to caption text.

Tier 2.2 — phase_embed_figures + orchestrator-side stale-file cleanup
  paper_writer.sh: new phase_embed_figures runs after
  phase_check_figures_manifest, before phase_check_scope_coherence.
  Walks 02_results.md/01_methods.md/03_discussion.md for (Fig. N)
  callouts; injects ![Figure N: caption](figures/<filename>) after
  first-occurrence-per-N's containing sentence. Multi-figure callouts
  inject all in N-ascending order; subsequent refs stay textual.
  Idempotent. Implementation in paper_writer_helpers.py:
  cmd_embed_figures + _find_sentence_end_after (skips Fig. N internal
  periods, e.g. lowercase abbreviations) + _build_figure_map +
  _embed_figures_in_text. 14 unit tests in
  tests/unit/test_embed_figures.py.

  Stale-file cleanup (D-025, drafting-mode-only): phase_results
  removes pre-existing figures/fig*.png before invoking results.v1.
  Fixes v0.2.1 rewrite-loop residue collisions. Skip in REPAIR_MODE.

  Rewrite-loop integration: phase_embed_figures called inside
  phase_review_rewrite after each rewrite-pass re-assembly.
  Idempotent semantics ensure no double-injection.

Two new DECISIONS entries
  D-025: orchestrator owns <draft_dir>/figures/ for paper-order names;
         pre-clean stale files in phase_results.
  D-026: embedded image-tag form ![Figure N: <caption>](figures/<filename>);
         N from prose's (Fig. N) callout (not embedder-counted);
         caption from inventory via resolve-figures.

Test cleanup
