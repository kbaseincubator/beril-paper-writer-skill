v0.5.0 — caption-quality tightening (boilerplate-aware sufficiency gate
+ panel-count-scaled word cap)

Focused point release on top of v0.4.0's caption-richness tier,
addressing two findings from the v0.4 visual review:

1. Boilerplate-heavy notebook prose passed the v0.4 sufficiency gate
   but produced descriptor-derived captions full of dev-process
   metadata (`Purpose:`, `Approach:`, `Sections:` etc.) in the docx.
2. Multi-panel figures truncated mid-word at the universal 200-word
   cap on Source 4 LLM captions.

Two changes:

paper_writer_helpers.py:_passes_sufficiency_gate — swap
`_strip_heading_lines` for `_strip_prose_for_inline` in the word-count
check. The newer strip drops keyword headers (both `**X:**` and
`**X**:` bold idioms), inline-cascade keyword chains, project-internal
artifact references, numbered list items, and bold-Bold:Bold patterns.
Boilerplate-heavy notebook prose now correctly fails the gate
(post-strip word count <30 because keyword content is removed) and
routes to Source 4 LLM, which has explicit anti-pattern discipline
against the same boilerplate.

paper_writer_helpers.py:_caption_max_words — new helper:

  panel_count == 0  → 200 words (single-panel default)
  panel_count >= 1  → 200 + 50 * panel_count

cmd_build_caption_bundles uses this per-figure (computes panel_count
from descriptor.panels). A 4-panel figure (like fig 8 in
functional_dark_matter draft_3) gets 400 words; ICMJE convention
permits 300-400 words for complex multi-panel legends. The --max-words
CLI flag is preserved as a ceiling-override for testing but defaults
to None so the formula prevails.

Effect on functional_dark_matter draft_3 (validation pending Adam's
local re-run):

  - Figures 6/7/8/9/10 (v0.4 marked deterministic with boilerplate
    residue) now route to Source 4 LLM via the boilerplate-aware gate.
  - Multi-panel fig 8 gets a 400-word budget; LLM has room to describe
    each panel without truncation.
  - Validation cost: ~$0.50 LLM (was ~$0.30 in v0.4 with only 5 figures
    through LLM; v0.5 sends 8-10 figures through).

Tests: 430 total, 0 fail. New tests:
  - _caption_max_words formula (-1, 0, 1, 2, 3, 4, 6 panels)
  - v0.5 sufficiency gate: boilerplate-heavy fails; substantive passes
  - cmd_build_caption_bundles writes panel-scaled max_words per bundle
  - _build_draft test helper extended to emit _Panels:_ block in v2
    inventory (round-trip verified)

`_strip_heading_lines` is no longer called by the gate but is retained
as a stable helper for other future code paths.
