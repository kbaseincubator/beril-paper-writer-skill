v0.4.0 — caption-richness tier (Tier 8 + Source 4 LLM synthesis)

Closes the caption-richness gap identified at the v0.3.0 retest. v0.3
shipped manuscript.docx with 10 inline Pictures + 10 single-line
Caption paragraphs (one noun phrase per figure, REPORT-derived). v0.4
produces ICMJE-conventional one-paragraph captions averaging 77 words
on functional_dark_matter, with structured multi-source content from
notebook walk-back + matplotlib AST + LLM synthesis where deterministic
sources are sparse. Anti-fabrication discipline enforced both prompt-
side (figure_caption.v1.md) and post-checker-side
(check_caption_provenance.py).

Eight architectural pieces landed across Phases 0-4c per
smoke-test/v0_4_punch_list.md, plus Phase 5b/5c follow-on patches
driven by the live-retest visual review. Cumulative across the v0.4
cycle:

  - Phase 0: cosmetics (FIGURES_OUT_DIR explicit, fallback removed)
  - Phase 1a: notebook cell-attribution rewrite (walk-back model)
  - Phase 1b: structured CaptionDescriptor + v2 inventory schema
  - Phase 2: matplotlib AST extraction (Source 3) + multi-panel
  - Phase 3: descriptor flow-through to manuscript + assemble_docx
  - Phase 4a: figure_caption.v1.md prompt (294 lines)
  - Phase 4b: tools/check_caption_provenance.py (361 lines, 6th post-checker)
  - Phase 4c: phase_caption_synthesis + phase_check_caption_provenance
  - Phase 5b: ICMJE single-paragraph caption layout + boilerplate strip
              (keywords + project-internal artifacts + bold idioms +
              inline cascade + numbered lists + possessive cleanup)
  - Phase 5c: Source 4 loop-closure (LLM captions actually flow into
              the manuscript)
  - Defensive: manifest-prefix Path().name normalization

Live-retest evidence (functional_dark_matter draft_3): 10/10 figures
with ICMJE-form Caption paragraphs; sufficiency gate routed 5
deterministic + 5 to LLM ($0.30 LLM cost on Source 4 synthesis); zero
notebook-keyword boilerplate residue post-strip; provenance check 1
WARN (figure 4 fabricated '17' — caught and surfaced); validators 9
pass + 1 N/A overall pass. Cumulative draft cost $10.64 (above the $10
projection due to one-time recovery overhead from the manifest-prefix
bug; future fresh drafts project ~$7).

426 unit tests, 0 fail. New tests cover all eight phases plus the
five Phase 5b refinements + Phase 5c closure + manifest-prefix
regression.
